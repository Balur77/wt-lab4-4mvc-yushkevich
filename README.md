
# WT-4 — ASP.NET Core MVC

## Описание

Веб-приложение для управления складскими грузами.
Реализовано на C# с использованием ASP.NET Core MVC и Razor Views.

## Функциональность

- Просмотр каталога грузов
- Просмотр подробной информации
- Добавление грузов
- Редактирование грузов
- Удаление грузов
- Валидация данных
- Адаптивный интерфейс Bootstrap

## Технологии

- C#
- ASP.NET Core MVC
- Razor
- Bootstrap
- Docker
